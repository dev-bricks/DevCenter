# Store Listing — Русский (ru-RU)

## Название
DevCenter Suite — Центр разработки Python

## Краткое описание
Рабочая станция для Python: сборка PyInstaller, статический анализ кода, быстрый поиск и ИИ-помощь.

## Полное описание
DevCenter Suite — это современная рабочая станция для разработчиков на Python. Приложение объединяет автоматизированную сборку исполняемых файлов PyInstaller, статический анализ кода, быструю локальную индексацию файлов на базе SQLite, синхронизацию проектов и инструменты помощи разработчику.

## Основные возможности
- **Сборка и упаковка:** Создание исполняемых файлов Windows (.exe) в один клик с проверкой зависимостей.
- **Анализ кода и метрики:** Детальный анализ сложности, структуры и потенциальных дефектов кода.
- **Быстрый индекс файлов:** Мгновенный поиск по крупным проектам с помощью локальной базы SQLite.
- **Синхронизация проектов:** Надежное резервное копирование и фиксация состояний разработки.
- **Инструменты разработчика:** Генератор иконок, исправление кодировок файлов и сбор лицензий компонентов.
- **Конфиденциальность и локальность:** Все исходные коды, настройки и индексы хранятся строго локально на ПК.
