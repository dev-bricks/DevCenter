# Store Listing — 日本語 (ja-JP)

## タイトル
DevCenter Suite — Python 開発者センター

## 簡単な説明
Python向けローカル開発ワークステーション：ビルド、コード解析、高速ファイル索引、AI支援。

## 詳細な説明
DevCenter Suite は、Python 開発者のために設計された高性能デスクトップ統合開発ワークステーションです。PyInstaller による自動実行ファイル作成、静的コード解析、SQLite ベースの超高速ファイル検索、プロジェクト同期、AI 支援機能を洗練されたユーザーインターフェースに統合しています。

## 主な機能
- **ビルド＆パッケージング：** ワンクリックで Windows 向け EXE ファイルを生成、依存関係を自動検出。
- **コード解析とメトリクス：** 複雑度、関数構造、潜在的な問題を詳細に可視化・分析。
- **高速ファイルインデックス：** ローカル SQLite データベースを活用し、大規模プロジェクトでも即座に検索。
- **プロジェクト同期：** 確実なバックアップと開発状態の追跡・同期。
- **開発ツールセット：** アイコン作成ツール、文字エンコード修復、サードパーティ製ライセンス一覧出力。
- **プライバシー保護：** ソースコードや設定データはすべてローカル端末内にのみ保存され、外部送信されません。
