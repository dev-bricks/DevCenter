# Store Listing — 简体中文 (zh-CN)

## 标题
DevCenter Suite — Python 开发者中心

## 简短描述
Python 本地开发者工作站：自动化构建打包、代码静态分析、快速文件索引与智能辅助。

## 完整描述
DevCenter Suite 是一款专为 Python 开发者打造的现代化桌面开发工作站。它集成了基于 PyInstaller 的自动化打包构建、静态代码分析、高性能本地文件检索、项目状态同步以及智能辅助功能。

## 主要功能
- **构建与打包：** 一键生成 Windows 独立可执行程序（.exe），自动检测并校验项目依赖项。
- **代码静态分析与指标：** 全面分析 Python 代码复杂度、结构分布及潜在缺陷。
- **快速文件索引：** 基于本地 SQLite 引擎，在大型代码库中实现毫秒级快速全文与文件名检索。
- **项目同步与备份：** 安全稳定的项目版本快照与文件状态同步机制。
- **实用开发工具链：** 内置 Windows 图标生成器、文本编码智能修复及第三方依赖许可证审计。
- **隐私保护与本地优先：** 所有源代码、项目配置文件及搜索索引数据均 100% 留存在本地设备。
