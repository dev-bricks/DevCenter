# Store Listing — English (en-US)

## Title
DevCenter Suite — Python Developer Center

## Short Description
Local developer desktop hub for Python: build, code analysis, file indexing, sync, and AI help.

## Description
DevCenter Suite is a modern desktop workstation for Python developers. It brings together automated PyInstaller builds, static code analysis, fast local file indexing, repository sync, and AI-assisted development in a responsive user interface.

## Features
- **Build & Packaging:** One-click generation of Windows executables with automated dependency scanning.
- **Code Analysis & Metrics:** Comprehensive code complexity and structural analysis for Python codebases.
- **Fast File Index:** Instant search across large project directories powered by a local SQLite index.
- **Project Sync:** Reliable tracking, backup, and synchronization of project states.
- **Developer Toolchain:** Built-in icon generator, encoding repair, and third-party license inventory.
- **Offline & Privacy:** All project data, source code, and indexes remain 100% on your local machine.
