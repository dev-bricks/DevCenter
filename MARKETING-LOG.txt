1. POSITIONING & VALUE PROPOSITION
===============================================================================
DevCenter is a local-first, zero-egress Python desktop IDE and developer toolkit
designed specifically for Windows 10/11 environments. It brings together Python code
editing, AST static analysis, automated encoding repairs, one-click PyInstaller
EXE compilation, icon generation, third-party license collection, full-text SQLite
file indexing, and an optional, secure Claude AI assistant into a cohesive,
standalone PySide6 desktop suite.

Key Differentiators:
- 100% Local-First & Zero-Egress: Operates entirely offline; no mandatory telemetry,
  no cloud accounts, no background data leakage.
- Python Desktop Focus: Tailored directly for building, inspecting, testing, and
  bundling Python desktop and CLI applications.
- One-Click EXE Packaging: Built-in PyInstaller pipeline with multi-resolution
  Windows ICO conversion and automatic license compliance notices.
- Non-Executing Static AST Analysis: Fast method, class, and cyclomatic complexity
  inspections without running untrusted user scripts.
- Secure AI Isolation: Optional Claude API integration uses native Windows Credential
  Manager (keyring) and strictly opt-in prompt dispatch.

===============================================================================
2. TARGET PERSONAS
===============================================================================
[PERSONA-01] Windows Python Desktop Application Developers & GUI Builders
- Profile: Python developers building Qt, PySide6, PyQt, or Tkinter desktop apps.
- Pain Points: Complex PyInstaller command lines, manual ICO multi-resolution creation,
  scattered license notices, tedious encoding corruptions (mojibake).
- How DevCenter Wins: Integrated PyInstaller GUI, automated icon converter,
  automated third-party license generator, and built-in ftfy encoding repair.

[PERSONA-02] Solo Maintainers & Local-First Engineers
- Profile: Open-source maintainers and indie hackers managing multiple Python packages.
- Pain Points: Heavyweight IDE startup lag (Electron/Java), memory consumption,
  opaque background processes, cumbersome project switching.
- How DevCenter Wins: Lightweight PySide6 native GUI, instant startup, fast
  SQLite full-text index, clean workspace export snapshots.

[PERSONA-03] Security-Conscious Enterprise & Air-Gapped Developers
- Profile: Engineers working in regulated, corporate, or air-gapped networks.
- Pain Points: IDEs requiring cloud logins, intrusive telemetry, automatic code
  exfiltration, unverified transitive dependencies.
- How DevCenter Wins: Zero egress by default, strict fail-closed vulnerability
  floors, unprivileged RunAsInvoker execution, full SBOM transparency.

[PERSONA-04] AI-Assisted Python Prompt Engineers & Agent Builders
- Profile: Developers pairing with LLMs (Claude, GPT, Gemini) for rapid prototyping.
- Pain Points: Copy-pasting massive file trees, accidental leakage of API keys,
  cluttered prompt context.
- How DevCenter Wins: Redacted workspace export (`devcenter-workspace-v1.json`),
  machine-readable `llms.txt`, secure keyring secret storage.
