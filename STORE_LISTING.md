## Deutsch

### Name
DevCenter Suite — Python Entwickler-Zentrale

### Kurzbeschreibung (100 Zeichen)
Lokale Entwickler-Zentrale für Python: Build, Code-Analyse, Datei-Index, Sync und KI-Assistenz.

### Beschreibung
DevCenter Suite ist eine leistungsfähige desktop-basierte Arbeitsumgebung für Python-Entwickler. Sie vereint automatisierte Builds mit PyInstaller, statische Code-Analyse, ein schnelles Datei-Indexierungssystem, Repository-Sync und KI-unterstützte Entwicklung in einer modernen Benutzeroberfläche.

**Kernfunktionen:**
- **Build & Packaging:** Ein-Klick-Erstellung von Windows-Executables mit automatischer Abhängigkeitsprüfung.
- **Code-Analyse & Metriken:** Detaillierte Analyse von Komplexität, Codestruktur und potenziellen Fehlerquellen.
- **Schneller Datei-Index:** Sofortiges Durchsuchen großer Projektstrukturen mit lokalem SQLite-Index.
- **Projekt-Sync:** Konsistente Sicherung und Synchronisation von Entwicklungsständen.
- **KI-Assistenz:** Integrierter Assistent für Code-Reviews, Refactoring und Fehlerdiagnose (optional per Claude API).

**Datenschutz:**
DevCenter Suite arbeitet primär offline. Projektdaten, Quellcode und Einstellungen verbleiben lokal auf Ihrem Rechner. Netzwerkverbindungen werden nur für vom Nutzer angeforderte Aktionen (z. B. Paketinstallationen oder KI-Anfragen) aufgebaut.

## English

### Title
DevCenter Suite — Python Developer Center

### Short Description (100 characters)
Local developer desktop hub for Python: build, code analysis, file indexing, sync, and AI assistance.

### Description
DevCenter Suite is a powerful desktop workstation for Python developers. It brings together automated PyInstaller builds, static code analysis, fast local file indexing, repository sync, and AI-assisted coding in a sleek, modern user interface.

**Key Features:**
- **Build & Packaging:** One-click generation of Windows executables with automated dependency scanning.
- **Code Analysis & Metrics:** Comprehensive code complexity and structural analysis.
- **Fast File Index:** Instant search across large project directories powered by a local SQLite index.
- **Project Sync:** Reliable tracking and synchronization of project states.
- **AI Assistance:** Built-in AI helper for code review, refactoring, and debugging (optional via Claude API).

**Privacy First:**
DevCenter Suite operates locally. All source files, project data, and settings remain on your machine. Network activity only occurs when explicitly initiated by the user.
